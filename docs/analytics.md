# 방문자 통계 (Vercel Web Analytics)

## 왜 이걸 골랐나

배포처가 이미 Vercel이라(`docs/deployment.md`) 계정을 새로 만들 필요 없이 패키지 하나로 끝난다.
GA4는 도시 단위까지 보여주지만 계정·속성·측정 ID 세팅이 따로 필요해서, 지금 단계에선 과하다고 봤다.

## 무엇을 볼 수 있나

- 방문자 수(고유), 페이지뷰(방문 횟수)
- **국가**, 유입 경로(referrer), 페이지별 조회수, 브라우저/OS/기기
- 도시는 안 나온다 — 무료 플랜은 국가까지다. 도시가 꼭 필요해지면 GA4를 따로 붙인다.
- Hobby 플랜 제한: 이벤트 월 2,500건, 데이터 보관 1개월.

## 어떻게 붙였나

1. `npm i @vercel/analytics`
2. `src/main.jsx`에서 `<App />` 옆에 `<Analytics />` 렌더링 — 이 컴포넌트가 페이지 로드마다
   Vercel로 익명 이벤트를 보낸다. 별도 설정값(키 등)은 없다.
3. Vercel 대시보드 → 프로젝트 → **Analytics** 탭에서 **Enable** 클릭 (한 번만).
4. 배포 후 실제 방문이 있어야 숫자가 뜬다. 로컬(`npm run dev`)에서는 수집되지 않는다.

개인정보: 쿠키를 쓰지 않고 개인을 식별하지 않는다(IP는 저장 안 하고 국가 판별에만 씀).
