# 학습 노트

2주차부터 같이 개발하면서 나온 핵심 개념·코드를 정리해두는 곳. FE / BE / DB / AI 네 영역으로 나누고, 각 영역 안에서 개념 하나당 파일 하나로 쪼갠다. 같은 개념이 나중에 또 나오면 새 파일을 만들지 않고 기존 파일에 이어서 추가한다.

- `fe/` — 프론트엔드 (React 컴포넌트, 상태 관리, 라우팅 등)
- `be/` — 백엔드 (Express 라우트, 미들웨어, 인증 등)
- `db/` — 데이터베이스 (Prisma, 스키마 설계, 쿼리 등)
- `ai/` — AI 에이전트 (손님/평가 에이전트, 루브릭, 프롬프트 설계 등)
